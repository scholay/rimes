XSIME is an independent keyboard and text assistant. It does not bundle a chatbot account, provider credentials, an AI subscription, a preset service endpoint or a preset model. We do not operate a hosted AI service. Ordinary typing and Buffer editing remain available offline without an account or Full Access.

The optional connection requires the user to enter their own HTTPS endpoint, model and API key. An AI action sends explicitly submitted Buffer text to the user-configured chat/completions endpoint only after recipient consent. The separate, explicit model-list lookup sends the key to that configured provider without Buffer text. Apple on-device translation is a separate feature with no external AI fallback.

The change from build 59 to build 60 is explanatory display text, not a change to network functionality. We have not disabled the user-configured connection or introduced China-specific endpoint restrictions. We are not claiming that a functional restriction has been implemented.
