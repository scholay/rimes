PRIVACY

Your words,
your control.

Effective: 22 September 2026 · Publisher: Haiyang Cui · 中文

Ordinary typing stays on your device

RIMES runs ordinary input locally. Learned word frequencies, keyboard preferences and custom mappings stay on this device. RIMES has no account system, cloud synchronization, ads, advertising identifiers or keyboard-text telemetry.

Buffer and composition

Buffer drafts and plugin results remain in keyboard-session memory and are cleared when the keyboard session ends. Unconfirmed composition appears in the current input field or Buffer. Text you explicitly insert becomes part of the host app’s document and is governed by that app’s privacy practices.

Optional Apple translation

Apple translation uses downloaded on-device language models through Apple’s Translation framework. Preparing languages in the containing app can require an internet connection and Apple’s system download flow. If local translation is unavailable, RIMES does not automatically send your text to an external AI service.

Optional provider-based AI

You choose an HTTPS provider, model and API key. After granting recipient consent, you may explicitly submit Buffer text for translation, polishing or rewriting. The request includes that text, the requested operation, model identifier and authentication key. RIMES does not automatically send host documents, clipboard contents or background typing history.

Your provider may associate requests with its API account. Its retention, training, access and deletion practices apply; RIMES cannot make those promises for the provider. Provider-based AI requires keyboard Full Access. Ordinary typing and Buffer work without it.

Keys, storage and deletion

API keys use this device’s Keychain and are excluded from configuration exports. Requests do not follow redirects. You can delete a provider and its key, withdraw recipient consent or disable Full Access. Uninstalling an app does not guarantee Keychain deletion: remove providers first and revoke keys at the provider when needed. RIMES does not operate a server containing your typing history.

This website and contact

This documentation site is hosted by GitHub Pages and uses no analytics scripts or advertising cookies. GitHub may process standard connection data under its privacy statement. For support or a privacy question, contact the RIMES project. Public issues are visible to others; do not post API keys or private input text.

中文隐私政策

生效日期：2026 年 9 月 22 日。发布者：Haiyang Cui。

普通输入在设备本地运行。学习词频、键盘偏好和自定义映射保存在本机；RIMES 不提供账户、云同步、广告，也不收集键盘输入正文日志。

Buffer 草稿和插件结果只保存在键盘会话内存中，结束会话后清除。你明确插入的文字会进入宿主 App 的文档，并受该 App 的隐私政策约束。

苹果翻译使用下载到设备的语言模型。主 App 的语言准备会调用苹果系统下载流程，可能需要网络。无法使用本地翻译时，RIMES 不会自动改用外部 AI 服务。

外部 AI 为可选功能。你自行配置 HTTPS 服务、模型和 API Key；同意接收方并主动提交后，才发送 Buffer 原文、操作指令、模型标识和认证 Key。不会自动发送宿主文档全文、剪贴板或后台打字记录。服务方可能将请求关联到 API 账户，其保留、训练和删除政策由该服务方决定。外部 AI 需要完全访问，普通输入和 Buffer 不需要。

API Key 保存在本设备 Keychain，不随配置导出；请求不跟随重定向。可删除服务和 Key、撤销发送许可或关闭完全访问。卸载不保证系统删除 Keychain 项目，建议先删除配置，必要时到服务方撤销 Key。

本支持网站由 GitHub Pages 托管，不使用广告或分析脚本。GitHub 可能按其隐私声明处理常规连接数据。隐私问题可通过项目的 GitHub 联系入口提出；公开问题中请勿附带 Key 或私人输入内容。
