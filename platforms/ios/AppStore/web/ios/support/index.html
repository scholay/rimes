中文帮助

Enable RIMES

  1. Open iPhone Settings → General → Keyboard → Keyboards.
  2. Choose Add New Keyboard, then RIMES.
  3. Focus a text field and use the system globe to select RIMES.

Full Access is optional for ordinary input and Buffer. Secure fields and apps that prohibit third-party keyboards always use the system keyboard.

Input and slide chords

The short scheme button changes input methods and remembers the last choice. Chord mode uses one starting key and endpoint per hand; both hands release to enter once. Letters passed during a slide do not accumulate. The right-side controls open emoji and switch Simplified/Traditional output.

Buffer

Tap the stacked-layers button to open Buffer. Compose locally, then tap the paper plane for the next block or hold for one second to insert everything remaining. More contains clear, cursor movement and explicit source insertion. Confirm a candidate before switching input fields if you want to commit the Chinese text. Hiding the keyboard ends the session and clears drafts.

Translation unavailable?

Apple translation requires iOS 26 or later and supported, installed language models. Open Apple translation languages in RIMES and finish the system preparation first. Enable the translation plugin manually inside Buffer. Only confirmed text triggers translation; stale, incomplete or failed results cannot be inserted.

Optional AI

Add your own HTTPS Chat Completions provider, model and API key in RIMES. Enable Full Access for keyboard AI, confirm the recipient and choose a Buffer action. Provider accounts and charges are separate. You can keep using ordinary input without a provider.

Report an issue

Open a support issue with your iPhone model, iOS version, RIMES version, input scheme and reproduction steps. Remove private text from screenshots. Never include API keys.

中文使用帮助

  1. 打开系统设置 → 通用 → 键盘 → 键盘。
  2. 点击“添加新键盘”，选择 RIMES。
  3. 回到输入框，使用系统地球键切换至 RIMES。

顶部方案按钮切换全拼、自然码、五笔、英文或并击，并记住上次选择。并击时每只手取起点和当前终点，双手全部释放后结算一次。右侧按钮提供表情和简／繁切换。

叠层图标打开 Buffer。纸飞机按钮单击逐块插入，长按一秒插入剩余整段。更多菜单包含清空、光标移动和原文插入。切换输入框前可先选定候选词；隐藏键盘会结束会话并清空草稿。

苹果翻译需要 iOS 26 及以上及已安装的受支持语言模型。先在主 App 的“苹果翻译语言包”中完成系统准备，再在 Buffer 手动选择翻译插件。未确认组词不会触发翻译；过期、处理中或失败的结果不能插入。

外部 AI 需要自己的 HTTPS 服务、模型和 Key，并开启完全访问及接收方许可。普通输入和 Buffer 无需完全访问。密码框及禁止第三方键盘的 App 会使用系统键盘。

遇到问题可通过 项目反馈入口提供设备、系统、App 版本、方案和复现步骤。请勿公开 API Key 或私人输入内容。
