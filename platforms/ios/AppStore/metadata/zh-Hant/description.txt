RIMES 將離線中文輸入、滑動並擊和寫作 Buffer 放進 iPhone 鍵盤。

支援全拼、自然碼雙拼、五筆 86 和英文，記住上次使用的方案。可切換簡體與繁體，並提供常用表情面板。

雙拇指滑動並擊
每隻手以起點和目前終點組成按鍵組合，可組合鍵位保持清晰，其餘鍵位淡出。雙手全部放開後結算一次。可複製或匯入 JSON 映射，調整自己的鍵位方案。

先整理，再插入
在 Buffer 中組織文字，點一下插入下一塊，長按一秒插入剩餘整段。未確認的組詞顯示在游標處，不再獨佔鍵盤一行。原文與外掛結果分開處理，由你明確選擇插入。

iOS 26 及以上可使用 Apple 裝置端翻譯，為已確認的 Buffer 原文提供翻譯預覽。請先在主 App 準備所需語言；可用性取決於系統支援的語言和已下載模型。

你也可以設定自己的 HTTPS AI 服務、模型和 API Key，使用翻譯、潤飾與改寫。只有在你同意接收方並主動提交後，才傳送所選 Buffer 原文。第三方服務可能另行要求帳戶或付費。

普通輸入和 Buffer 編輯可離線使用，不需完整取用、帳戶或訂閱。無廣告，不收集鍵盤輸入正文紀錄。僅可選的外部 AI 功能需要完整取用。密碼欄位和不允許第三方鍵盤的 App 使用系統鍵盤。

支援 iOS 17 及以上的 iPhone。App 介面提供英文和簡體中文；文字輸出可切換繁體。觸覺回饋取決於裝置與系統設定。
