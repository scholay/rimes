# Android 1.1.0 candidate: official plugins and configurable AI

Source: host `codex/release-1.1.0`, official plugin source pin `854f45f`.
This record covers a local debug candidate on a connected physical Xiaomi phone,
not a published release or a signed production upgrade.

- Fresh arm64-v8a and x86_64 native engine builds and 16 KB alignment checks passed.
- Core tests, debug APK, instrumentation and native input test-host builds passed.
- Real-device instrumentation: official package lifecycle 23 checks; AI routing and
  encrypted-profile policy 54; service delivery 156; backend 68; grouped settings 382.
- Custom HTTPS base URLs and full chat-completion URLs reach the configured recipient.
  Invalid URLs fail before connecting. Cross-host/port changes require a new key.
  Old profiles preserve their CometAPI endpoint, model and encrypted credential.
- A maintainer-supplied temporary key called `https://api.deepseek.com/chat/completions`
  with model `deepseek-flash`, following the [official API](https://api-docs.deepseek.com/api/create-chat-completion/).
  The initial real Android SSE request completed in 955 ms (five callbacks).
- The actual keyboard then ran quick question, polish and translation requests.
  In the test host, `we is happy today` became `We are happy today.` and
  `good morning` became `早上好`. Complete replies were manually inserted exactly once.
  Observed test-run times were approximately 2.12 s, 1.82 s and 1.68 s, respectively;
  these are single-request observations, not a provider latency guarantee.
- The same run passed cancellation, target loss, private/password input and
  no-send-before-completion checks: 202 assertions.
- Disable/re-enable invalidates old result grants; uninstall preserves source and
  user documents; late downloads cannot resurrect an uninstalled plugin.
- Live testing restored the previous encrypted AI profile and plugin state afterward.
  No credential is included in repository files or test output.

Downloaded-package networking still needs the public 1.1.0 assets to exist before
final release acceptance; offline package fixtures are not evidence of a public download.
