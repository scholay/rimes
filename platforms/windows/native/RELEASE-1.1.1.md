# RIMES Windows 1.1.1

修复 Windows 1.1.0 的设置和卸载入口，并加入社区反馈修复。面向 Windows 11 x64，包含 x64 Broker、x64/x86 TSF 和微软 VC++ 运行库。x86 TSF 用于 32 位宿主，不代表支持 32 位 Windows。

## 本次更新

- 开始菜单搜索 **RIMES Settings** 可直接打开设置；已有 Broker 时复用同一进程。打开设置保留 Buffer 草稿和结果，返回宿主后需明确重新绑定。
- 在 Windows **设置 → 应用 → 安装的应用** 或控制面板 **程序和功能** 中提供 RIMES 卸载入口；默认保留词库、设置和凭据。
- Explorer 重启后恢复托盘图标；普通桌面启动不保留黑色控制台窗口。
- 修复 Shift 组合的可打印符号处理，包括问号；保持并击与快捷键行为。
- 设置可调整每页候选数（1–9）和竖排；改善候选位置临时不可用时的跳角，以及设置侧栏悬停闪烁。
- 安装状态文件丢失或损坏时，根据本项目实际注册路径恢复；可修复经过校验的缺失安装文件，或清理缺失 DLL 的本项目注册。用户数据保留。

## 下载与升级

从 [Windows 1.1.1 发布页](https://github.com/scholay/rimes/releases/tag/windows-v1.1.1) 下载 `RIMES-Windows-1.1.1-Setup.exe`，核对 `SHA256SUMS` 后运行。EXE 未签名，Windows 可能显示未知发布者或 SmartScreen 提示；安装器不修改系统安全设置。

升级前保存 Buffer 内容，从 RIMES 托盘退出，并使用安装时的同一 Windows 用户授权管理员权限。运行新 EXE 覆盖升级，无需先卸载；词库和设置保留。若安装器提示注销或重启，保存其他工作后按提示执行，以卸载宿主已加载的旧输入法 DLL；安装器不会自动注销或重启。

安装后用 Win+Space 选择 RIMES，在开始菜单搜索 **RIMES Settings**。托盘右键也可打开设置。旧版的临时入口是输入框按 Ctrl+Alt+B，再在 Buffer **… → 设置** 中进入。

## 验证范围

正式包的源码提交、两架构构建、CTest、真实引擎/TSF 探针、安装器测试和包哈希记录在发布附件 `BUILD-INFO.json`。已有内部修复包的开始菜单、系统卸载入口和 Explorer 托盘恢复有 Young 桌面验收记录；它们不替代本次正式安装包的验收。完整应用兼容性、多屏/DPI、登录/锁屏恢复和长期日用仍需持续验证。
