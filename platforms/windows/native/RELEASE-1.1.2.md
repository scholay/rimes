# RIMES Windows 1.1.2

本补丁修复普通输入与既有 Buffer 的按键行为，面向 Windows 11 x64，包含 x64 Broker 和 x64/x86 TSF。

- 修复轻按 Shift 提交原码或切换中英文时遗漏输入的问题；保持宿主快捷键、长按、重复和焦点切换的行为。
- Buffer 不截获带 Ctrl、Alt 或 Win 的回车、退格和 Esc。容量已满或结果正在上屏时，Shift 松开仍传给宿主，保留原来的组合输入和待发结果。
- 切回普通输入停止旧的处理请求，保留原文、已完成结果和已发出的投递。
- 新配置使用 Ctrl+Shift+B；保留已有 Ctrl+Alt 快捷键。修改快捷键遇到冲突或保存失败时继续使用旧组合。

下载正式发布页的 EXE，核对 SHA256SUMS 后覆盖升级。升级前保存 Buffer 内容并从托盘退出 RIMES；安装器保留词库和设置。EXE 沿用未签名分发方式。若安装器要求注销或重启，请先保存其他工作。

源码与包身份、两架构测试、安装验收及校验和以该版本的 BUILD-INFO.json 为准。跨账号管理员授权安装、损坏安装的完整卸载重装及更多宿主/DPI 场景继续由对应 Issue 跟踪。
