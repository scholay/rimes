安装须知

支持 macOS 13 及以上，安装时需输入管理员密码。

macOS 27 有用户报告：安装后在 App Store 沙盒版微信、QQ 中切换到 RIMES，应用可能闪退。安装器不会清理其他应用的缓存。若遇到问题，请先切回其他输入法，查看按应用备份缓存的恢复指引及 issue #90。

On macOS 27, a user reports crashes when switching to RIMES in App Store sandboxed WeChat or QQ. This installer does not clear other apps' caches. If affected, use another input method and consult the per-app recovery guide.
