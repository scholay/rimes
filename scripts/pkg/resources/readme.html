系统要求

  • macOS 13 (Ventura) 或更高
  • Apple Silicon 或 Intel（通用二进制）

安装说明

  • 本安装器需要管理员密码，会把「RIMES」装到 /Library/Input Methods（所有用户可用）。
  • 安装时若存在普通 GUI 用户会话，会在该会话里尝试注册、启用并切换到「RIMES」；否则只安装程序文件，登录后再从系统设置中激活。
  • 从官方 GitHub Releases 下载的正式安装包使用 Developer ID 签名并经 Apple 公证；自行构建的开发包除外。

安装之后

多数情况下安装完成后即可用输入菜单或 Ctrl-Space 切换。若菜单没有刷新，请先注销并重新登录，再在系统设置中确认「RIMES」；无需结束 macOS 的系统进程。
