# 1.1.0 发布计划

范围：macOS、iOS、Android、Windows。Linux 保留现状。源码、构建、安装、实机体验、审核与公开发布分别验收。

## 顺序与证据

1. **已完成**：整合 PR #48 于 2026-10-04 合入主线 `29dfecc9764a31f648976de41acd7fed82d2f554`。macOS、iOS、Android、Windows、Linux 与 macOS 打包 CI 全部通过。
2. **进行中**：本体固定插件仓提交和文件摘要，建立统一清单、平台别名、宿主能力及安装生命周期。原生实现由插件仓维护，随宿主编译；下载内容不装载任意可执行代码。
3. **首个本地闭环已通过**：Polisher 的下载内容实际进入请求；校验摘要、安装后停用、显式启用与选择、停用/卸载取消、迟到结果拒绝、重装重新授权、旧用户离线保留及原文/配置保留均有测试。LaTeX 使用同一来源和指令通道。
4. **进行中**：原生实现已迁入插件仓并固定提交；macOS、iOS、Android 消费端已完成本地测试，Windows 消费端与并击仍待完成。macOS 清单是 21 个（13 预装、8 下载），不是全平台数量；保留手机快问、作诗、字符画。Windows 并击为发布必需项，音乐允许仅 macOS。
5. **待完成**：四平台独立构建、安装与实际输入验证；全部默认配置及用户升级流程验收。
6. **待完成**：macOS 签名、公证；Android 长期密钥签名；Windows EXE 安装包（允许不签名）；iOS 上传及真实审核状态确认。插件资产先可用，再发布依赖它们的本体。

## 当前边界

- 统一 SDK 验证 11 类贡献；24 个插件声明平台适配。macOS 60 项 smoke、三种外观各 22 个设置页面、Shared 78 项测试、iOS 全量模拟器测试已通过。Android 真机已通过插件生命周期、网络策略、发送权限、后端与设置界面测试。Windows 仍需实际接入与验证。
- Android API 地址、模型和密钥可配置，保留旧 CometAPI 配置；已使用 DeepSeek 官方接口在真机验证实际 SSE 回复，实际键盘快问、润色、翻译与取消/输入目标/隐私边界共 202 项断言通过。
- 所有预装/下载插件最终需支持统一启停与逻辑卸载，卸载保留用户数据；隐藏 Mailbox 终端入口不终止已接受的终端任务。
- 1.0 用户插件权限不能因迁移丢失；新安装插件不能自动启用、选中或发起请求。
- 维护工作在交付分支完成，保留原工作区。设备上旧版的可用体验不能作为 1.1.0 已验收证据。
- 本文是执行记录，不是公开发布公告；未完成项目不算已交付。
