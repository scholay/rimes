# Windows 1.1.5 预览版：本轮真机验收清单

用途：由维护者在自己的 Windows 机器上复测。所有复选框初始为未验收；CI、模拟 TSF 和原生离屏渲染不能替代下面的真机操作。本清单随 EXE 交付，全部通过、相关 issue 留下验收记录后，在后续提交中删除本文件。

本轮范围：Windows 兼容性修复、Buffer 与设置界面对齐 macOS、isaac2026 键位编辑、Codex 和多个 OpenAI 兼容 API 配置。没有增加 Claude。普通第三方 Rime 方案导入继续保留。

## 记录安装身份

- 安装包版本：`1.1.5-preview.20261016`（程序内产品版本 `1.1.5`）。
- 将随包的 `BUILDINFO` / 清单中的 Git 提交、EXE 文件名和 SHA-256 复制到验收记录；不要只记“最新版”。
- 分支：`codex/windows-macos-parity-20261016`。
- 记录 Windows 版本、显示缩放、显示器组合、应用版本、是否从旧版本升级，以及输入法设置中的自定义快捷键。
- 新安装默认 Buffer 快捷键为 **Alt+Shift+B**，发送为 **Alt+Shift+Enter**。旧配置保留原快捷键；进入“设置 → Buffer → 快捷键”查看或修改。轻按发送下一块，长按默认 **1.2 秒**发送全部，可设为 500–3000 ms。
- 设置入口：系统托盘 XSIME 图标右键 → 设置。输入框中的 Buffer 右侧更多菜单也可进入设置。

## B. 设置界面与 Buffer

- [ ] 设置的侧栏、页面标题、分段导航、卡片、按钮、四套主题与 macOS 风格一致，数字/模型/地址均能编辑；窗口可移动到副屏，也可被普通窗口覆盖。
- [ ] “外观 → 主题”选择跟随 Windows 明暗；切系统主题后 Buffer 与候选同步。关闭跟随后使用所选固定主题；取消未保存编辑不改变已保存外观。
- [ ] “外观 → 尺寸”修改字体、数量、横/纵排、最大宽度、高度、序号字号和 Buffer 默认宽度；保存、重新打开以及重启后都保留。Buffer 有可靠输入框边界时跟随输入框宽度；无边界时使用默认宽度。
- [ ] 设置窗口 Tab/Shift+Tab、下拉框方向键/Enter/Esc 正常；操作下拉框不误保存或关闭窗口。
- [ ] 在 A 输入框唤出 Buffer，输入中文、英文、标点和多段文字，全部进入原文轨，宿主不抢先收到内容。更多菜单折叠/展开保留正文；再次输入自动展开。
- [ ] 轻按发送只送下一块；长按超过设定阈值送全部。长按产生的重复键和迟到抬键不追加宿主换行、不重复发送。
- [ ] 发送时切到 B 输入框：暂停投递，A/B 都不误收剩余文本。回到 A 或 B 后显式重新绑定才恢复；无可靠目标时可以复制。
- [ ] 收到插入确认后才消费块；投递失败/中断保留未发送内容。确认不明时提示核对，不自动重试。
- [ ] 关闭 Buffer 再打开保留本进程内容；退出 Broker/重启不恢复正文。AI 原文/结果切换、编辑原文使旧结果失效、显式复制/发送正常。
